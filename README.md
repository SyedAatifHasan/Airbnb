# 🏠 Airbnb-Inspired MERN Web Application

A full-stack Airbnb-inspired web application built as a hands-on project to explore modern full-stack web development.

The application allows users to browse properties, register and log in, make bookings, manage favourites, receive notifications, and interact with hosts. Hosts can manage their properties and booking requests through their own interface.

## ✨ Features

- 🔐 User authentication and authorization
- 🏠 Property listing and management
- 🔍 Property search and filtering
- ❤️ Favourite properties
- 📅 Property booking system
- 👤 Guest and host functionality
- 📋 Booking management
- 🔔 In-app notifications
- 📧 Email notifications
- 📊 Host dashboard and property insights
- 📂 File upload and download
- 📱 Responsive user interface

## 🛠️ Technologies Used

- **Node.js**
- **Express.js**
- **MongoDB**
- **Mongoose**
- **EJS**
- **JavaScript**
- **HTML5**
- **CSS3**
- **Tailwind CSS**

## 📌 Project Overview

The project simulates the core functionality of a property rental and booking platform.

### Guests can:

- Browse available properties
- Search and filter properties
- View property details
- Add properties to favourites
- Book properties
- View and manage their bookings
- Receive notifications and email updates

### Hosts can:

- Add and manage properties
- View booking requests
- Confirm or cancel bookings
- View property-related information
- Monitor property performance

## 🔐 Authentication

The application uses session-based authentication and authorization to manage users and protect restricted routes and functionality.
